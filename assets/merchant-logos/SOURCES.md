# Merchant logo assets

These images are bundled locally and are always available to identify recognized merchants beside transactions. For recognized keys, the avatar may additionally request a logo through [Unavatar's Google favicon provider](https://github.com/microlinkhq/unavatar#google) using a reviewed company-domain allowlist. The request contains only that public domain; it never contains a merchant description, merchant key, transaction, user identifier, or statement data. `fallback=false` ensures a failed online lookup leaves the bundled image or initials visible instead of substituting an unrelated generated avatar.

The primary assets are published Android application icons retrieved from each company's Google Play listing. The Amazon Pay wordmark is Amazon-authored artwork sourced from [Wikimedia Commons](https://commons.wikimedia.org/wiki/File:Amazon_Pay_logo.png), whose file record identifies `pay.amazon.com` as its original source. The Apple silhouette is sourced from the public [Wikimedia Commons Apple logo file](https://commons.wikimedia.org/wiki/File:Apple_logo_black.svg). The Reliance Retail mark was retrieved from the public website icon for `relianceretail.com`. Company names and marks remain trademarks of their respective owners.
